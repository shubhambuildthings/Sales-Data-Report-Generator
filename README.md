# Sales Data Report Generator

A Python-based data analysis and reporting tool that processes sales data from a CSV file, calculates key business metrics, generates visualizations, and automatically creates a professionally formatted PDF report.

## Features

- **CSV Data Processing:** Reads and processes sales records using Pandas.
- **Revenue Analysis:** Calculates total revenue, total orders, total units sold, and average order value.
- **Monthly Revenue Analysis:** Tracks revenue across different months.
- **Product Analysis:** Identifies revenue generated by each product.
- **Regional Analysis:** Compares sales performance across regions.
- **Data Visualization:** Generates charts using Matplotlib.
- **Automated PDF Reporting:** Creates a structured PDF report using ReportLab.

## Tech Stack

- Python
- Pandas
- Matplotlib
- ReportLab

## Installation

1. Clone the repository:

```bash
git clone https://github.com/shubhambuildthings/Sales-Data-Report-Generator.git
```

2. Navigate to the project directory:

```bash
cd Sales-Data-Report-Generator
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the main Python script:

```bash
python src/main.py
```

The program processes the sales data and generates:

- A PDF report inside the `reports/` directory.
- Revenue analysis charts inside the `charts/` directory.
